## Connector procedure and recovery

Use the connected Google Drive toolset and its current schemas. Discover tools rather than assuming connector names or upload formats are portable. Metadata reads establish MIME type, parents and canonical URLs before raw downloads. List each authorised source folder and resolve the IDs in source-manifest.json; a file moved outside the authorised folder is not an authorised source merely because its ID is known.

For stored Word files fetch the original bytes using the supported raw-file download route. Do not export them as native Google Docs or convert on upload. Materialise authenticated file references through the runtime; never embed access tokens, expiring download URLs or account credentials in this package. For the native master prompt retrieve complete readable content; confirm it is not truncated. If tools lack required retrieval capabilities, request the approved files and explain the blocker instead of inventing contents.

Find patient folders by exact parent and name, checking all result pages. When none exists, create once inside Patient Reports; on a timeout re-list before retrying to prevent duplicates. Multiple matching folders require clarification. Check existing filenames before uploads. A previous report is not safe to replace merely because it has the same name; obtain explicit authorisation for protected reports. Where a connector supports a permitted in-place update, preserve the file ID; otherwise retain existing files and ask how to version the new report.

After upload, read back metadata for both returned IDs and verify exact filename, Word MIME type, destination parent, size/checksum where exposed, and access settings. Return canonical links observed from successful results/readback. Do not synthesise success from an upload attempt. If an operation times out, inspect the destination before retrying. One supported retry after verification is sufficient; on repeated failure stop, preserve local DOCX files and provide truthful local delivery. Do not enable public links or widen permissions.
